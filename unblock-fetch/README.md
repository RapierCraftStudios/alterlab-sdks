# unblock-fetch

Fetch directly; use [AlterLab](https://alterlab.io) only when the site refuses the request. Requests that already work never leave your machine.

| Package | Install | Registry |
|---|---|---|
| [Node.js](node) | `npm install unblock-fetch` | [![npm](https://img.shields.io/npm/v/unblock-fetch?logo=npm)](https://www.npmjs.com/package/unblock-fetch) |
| [Python](python) | `pip install unblock-fetch` | [![PyPI](https://img.shields.io/pypi/v/unblock-fetch?logo=pypi&logoColor=white)](https://pypi.org/project/unblock-fetch/) |
| [MCP server](mcp) | `npx unblock-fetch-mcp` | [![npm](https://img.shields.io/npm/v/unblock-fetch-mcp?logo=npm)](https://www.npmjs.com/package/unblock-fetch-mcp) |
