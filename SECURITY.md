# Security policy

Please do not open public issues for security problems.

Report vulnerabilities in these SDKs or in the AlterLab API by email to [support@alterlab.io](mailto:support@alterlab.io) with "Security" in the subject, or follow the disclosure policy at [alterlab.io/security/disclosure](https://alterlab.io/security/disclosure).

Include the package name and version, what you found, and steps to reproduce. We acknowledge reports within two business days and will keep you updated until the issue is resolved.

Only the latest release of each package receives security fixes.
